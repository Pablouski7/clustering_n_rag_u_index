# Convenciones de Código y Nombres

Este documento establece las reglas de codificación y convenciones para el repositorio.

## Idioma
- Todo el código (variables, funciones, clases, docstrings, comentarios) se escribe en **español**.
- Los nombres de archivos y carpetas deben estar en minúsculas y usar guiones bajos (`snake_case`) o guiones normales (`kebab-case`) según corresponda.

## Estilo de Python
- Se sigue la guía de estilo PEP 8.
- Tipado estático (Type Hints) opcional pero recomendado en firmas de funciones públicas.
- Estructura limpia de imports, ordenados por: estándar, terceros, locales.
